# References

Este modulo centraliza os materiais de referencia utilizados no fluxo manual.

Estrutura:
- `prompts/` - conteudo ativo organizado por tipo de execucao
  - `reference/` - exemplos de execucao por etapa

Observacao: mantenha os arquivos organizados dentro de `prompts/`. Nao adicione arquivos soltos nesta pasta.
