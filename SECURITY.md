## Reporting a Vulnerability

We take the security of WorkflowAgentsAI seriously. If you believe you have found a security vulnerability, please report it to us as described below.

### How to Report

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via one of the following methods:

1. **Email**: Send details to eliterickytech@gmail.com
2. **GitHub Security Advisories**: Use the [Security tab](https://github.com/eliterickytech/WorkflowAgentsAI/security/advisories/new) to privately report a vulnerability

### What to Include

Please include the following information in your report:

- Type of vulnerability (e.g., XSS, SQL injection, information disclosure)
- Full paths of source file(s) related to the vulnerability
- Location of the affected source code (tag/branch/commit or direct URL)
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the vulnerability, including how an attacker might exploit it

### Response Timeline

- **Initial Response**: Within 48 hours
- **Status Update**: Within 7 days
- **Fix Timeline**: We aim to release patches within 30 days for critical vulnerabilities

### What to Expect

1. We will confirm receipt of your vulnerability report
2. We will investigate and determine the severity
3. We will work on a fix and coordinate disclosure timing with you
4. We will credit you in the security advisory (unless you prefer to remain anonymous)

## Security Best Practices

When using WorkflowAgentsAI:

1. **Keep Dependencies Updated**: Regularly update Python packages and GitHub Actions
2. **Secure Credentials**: Never commit API keys, tokens, or credentials to the repository
3. **Review Generated Code**: Always review code generated by agents before deploying to production
4. **Access Control**: Limit access to sensitive business requests and attachments
5. **Environment Isolation**: Use separate environments for development, testing, and production

## Security Features

- **Input Validation**: All agent inputs are validated using JSON Schema
- **Encoding Standards**: Enforced UTF-8 encoding without BOM to prevent injection attacks
- **Dependency Scanning**: Automated via Dependabot
- **Code Analysis**: Regular CodeQL scans for Python code
- **CI/CD Security**: GitHub Actions workflows follow security best practices

## Security Updates

We announce security updates through:

- GitHub Security Advisories
- Release notes in CHANGELOG.md
- The #security channel in our community discussions

## Known Security Considerations

### Agent-Generated Content

- Agents generate code based on business requirements. Always review generated code for security implications.
- Be cautious with agents that handle sensitive data (PII, credentials, business logic).

### PowerShell Scripts

- PowerShell scripts in this repository require execution policy adjustments. Review scripts before running.
- Run scripts in isolated environments when testing.

### Python Code Execution

- Orchestrators (CrewAI, AutoGen) may execute arbitrary Python code. Use in controlled environments only.
