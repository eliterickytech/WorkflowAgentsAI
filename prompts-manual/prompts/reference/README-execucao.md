## Execução no VS Code com Copilot Chat (Agent)

Este guia permite rodar seus prompts diretamente no VS Code (Copilot Chat/Agents) sem usar uma API própria. O Copilot executa as ações no seu workspace (criar/editar arquivos) conforme você autoriza.

Pré-requisitos
- Abrir este repositório no VS Code.
- Ter GitHub Copilot habilitado (Pro) e o painel do Copilot Chat aberto.
- Defina o número da sprint (ex.: `1`). Usaremos a convenção `out/sprint<sprint>/`.

## Parâmetros e política de execução

- Preencha antes de rodar: Sprint (<sprint>) e, se desejar, Activity (<activity>). As saídas seguirão `out/sprint<sprint>` ou `out/sprint<sprint>/<activity>`.
- Política: Não faça perguntas. Se faltar informação, adote até 3 suposições razoáveis, liste-as no início do arquivo gerado e prossiga.
