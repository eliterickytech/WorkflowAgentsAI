## 👤 **User Story**
**Como** administrador do sistema WorkflowAgentsAI
**Quero** visualizar um dashboard principal com métricas e status dos projetos
**Para** ter controle centralizado e visibilidade das operações em tempo real

## 📋 **Acceptance Criteria**

### **Cenário 1: Visualização do Dashboard**
```gherkin
Dado que sou um administrador logado no sistema
Quando acesso a página principal (dashboard)
Então vejo as seguintes informações:
  - Total de projetos ativos
  - Workflows em execução (count + lista)
  - Status dos agentes (disponível/ocupado)
  - Métricas de uso dos últimos 30 dias
  - Gráfico de atividade por sprint
```

### **Cenário 2: Navegação para Projetos**
```gherkin
Dado que estou visualizando o dashboard
Quando clico em um projeto na lista
Então sou redirecionado para a página de detalhes do projeto
E vejo todas as sprints e atividades desse projeto
```

### **Cenário 3: Atualização em Tempo Real**
```gherkin
Dado que tenho o dashboard aberto
Quando um workflow é iniciado ou finalizado
Então as métricas são atualizadas automaticamente
E recebo uma notificação visual da mudança
```

### **Cenário 4: Responsividade**
```gherkin
Dado que acesso o dashboard em diferentes dispositivos
Quando o dashboard é carregado
Então o layout se adapta corretamente a:
  - Desktop (1920x1080)
  - Tablet (768px)
  - Mobile (375px)
```

## 🛠️ **Technical Tasks**

### **Frontend (Next.js + TypeScript)**
- [ ] **Setup inicial do projeto**
  - Configurar Next.js 14 com TypeScript
  - Setup Tailwind CSS + Shadcn/ui
  - Configurar ESLint + Prettier
  - Setup do Zustand para state management

- [ ] **Componentes do Dashboard**
  - Header com navegação e perfil do usuário
  - Cards de métricas principais (total projetos, workflows ativos, etc.)
  - Tabela de projetos recentes com status
  - Gráfico de atividade (usando Recharts)
  - Lista de workflows em execução

- [ ] **Integração com Backend**
  - Service layer para chamadas de API
  - Hook personalizado para fetch de dados
  - Error boundary para tratamento de erros
  - Loading states para melhor UX

### **Backend (ASP.NET Core)**
- [ ] **API Controllers**
  - `/api/dashboard/metrics` - Métricas gerais
  - `/api/dashboard/projects` - Projetos recentes
  - `/api/dashboard/workflows` - Status dos workflows
  - `/api/dashboard/activity` - Dados para gráficos

- [ ] **Services & Business Logic**
  - DashboardService para agregação de dados
  - ProjectService para dados de projetos
  - WorkflowService para status de workflows
  - Integration com estrutura atual de arquivos

- [ ] **Database Schema**
  - Tabela Projects (id, name, status, created_at, etc.)
  - Tabela Workflows (id, project_id, status, agent_current, etc.)
  - Tabela Metrics (date, project_count, workflow_count, etc.)
  - Views para agregações rápidas

### **Real-time & Integração**
- [ ] **SignalR Hub**
  - Hub para notificações em tempo real
  - Grupos por usuário/projeto
  - Events para mudanças de status

- [ ] **Integração com Sistema Atual**
  - Watcher para mudanças na pasta `out/`
  - Parser dos arquivos manifest.json
  - Monitor dos processos Python (orquestradores)
