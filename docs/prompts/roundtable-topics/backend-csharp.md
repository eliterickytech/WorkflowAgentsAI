# Tópicos Essenciais — Mesa Redonda (C#/.NET)

Use este roteiro quando o foco da mesa for Backend C#/.NET.

- Arquitetura: Clean Architecture, DDD, CQRS/MediatR, mapeamento de camadas
- Domínio: entidades, agregados, invariantes, value objects
- Validações: FluentValidation, error codes, Result pattern
- Persistência: EF Core, dapper, mapeamentos, migrações, transações, repositórios
- Logging/Observabilidade: Serilog, correlação, métricas e tracing
- Segurança: autenticação/autorização (JWT/AD), OWASP, secrets/config
- Performance/Resiliência: caching, pooling, paralelismo, retry/circuit breaker
- Integrações: contratos, versionamento, tolerância a falhas, mensageria
- Testes: unit (xUnit + FluentAssertions), integração (WebApplicationFactory), arquitetura
- CI/CD: qualidade (lint/analyzers), build, testes, migrações automatizadas
