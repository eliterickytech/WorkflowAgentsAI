# Tópicos Essenciais — Mesa Redonda (Frontend)

Use este roteiro quando o foco da mesa for Frontend.

- Framework: Angular ou React? Justificativa no contexto do projeto
- UI Library: PO-UI, Material, AntD, MUI, Design System corporativo
- Responsividade: breakpoints, grids, mobile-first, layout adaptativo
- Acessibilidade: diretrizes WCAG 2.1 AA, testes com axe, contraste e navegação por teclado
- Performance: bundle size, code splitting, lazy loading, caching, imagens otimizadas
- Integração: contratos de API, versionamento, autenticação (JWT, OAuth2)
- Componentização: componentes reutilizáveis vs específicos, guidelines de arquitetura
- Estado: estratégia (NgRx, Redux, Zustand, Signals), efeitos e observabilidade
- Theming: variáveis, tokens de design, dark mode, localidade/i18n
- Testes: unit (Jest/Karma), E2E (Cypress/Playwright), cobertura mínima
- Deploy/CI: build, empacotamento, CDN, cache policies
