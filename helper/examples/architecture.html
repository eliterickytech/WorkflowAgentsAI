Exemplo 1: Clean Architecture + DDD para Sistema de Comissões

Contexto:

Sistema de cálculo de comissões complexo usando Clean Architecture, DDD, CQRS e validações robustas.

Estrutura de Camadas:

src/
├── Domain/                          # Núcleo do negócio
│   ├── Entities/
│   │   ├── Vendedor.cs             # Aggregate Root
│   │   ├── Comissao.cs             # Entity
│   │   └── Venda.cs                # Entity
│   ├── ValueObjects/
│   │   ├── PercentualComissao.cs   # Value Object
│   │   ├── PeriodoCalculo.cs       # Value Object
│   │   └── MetaVendedor.cs         # Value Object
│   ├── DomainEvents/
│   │   ├── ComissaoCalculadaEvent.cs
│   │   └── MetaBatidaEvent.cs
│   └── Interfaces/
│       └── IComissaoRepository.cs   # Port
│
├── Application/                     # Casos de uso
│   ├── Commands/
│   │   ├── CalcularComissaoCommand.cs
│   │   └── CalcularComissaoHandler.cs
│   ├── Queries/
│   │   ├── ObterComissaoQuery.cs
│   │   └── ObterComissaoHandler.cs
│   ├── Validators/
│   │   └── CalcularComissaoValidator.cs  # FluentValidation
│   └── DTOs/
│       └── ComissaoDTO.cs
│
├── Infrastructure/                  # Detalhes técnicos
│   ├── Persistence/
│   │   ├── ComissaoRepository.cs    # Adapter
│   │   └── ComissaoDbContext.cs     # EF Core
│   ├── ExternalServices/
│   │   ├── TotvsApiClient.cs        # Integração ERP
│   │   └── SalesforceApiClient.cs   # Integração CRM
│   └── Logging/
│       └── SerilogConfig.cs
│
└── API/                             # Interface REST
    ├── Controllers/
    │   └── ComissoesController.cs
    ├── Middlewares/
    │   ├── ExceptionMiddleware.cs
    │   └── AuditMiddleware.cs
    └── Program.cs

Decisões Arquiteturais (ADRs):

  • ✅ ADR-001: Clean Architecture para desacoplar regras de negócio
  • ✅ ADR-002: CQRS com MediatR para separar leituras/escritas
  • ✅ ADR-003: DDD com Value Objects para validações ricas
  • ✅ ADR-004: Repository Pattern para abstração de dados
  • ✅ ADR-005: FluentValidation para regras de validação
  • ✅ ADR-006: Serilog para logging estruturado (auditoria SOX)

Exemplo 2: Microservices com Event-Driven Architecture

Contexto:

Sistema de e-commerce com microservices, mensageria assíncrona e eventual consistency.

Arquitetura de Microservices:

Microservices:
┌─────────────────────────────────────────────────────────────────┐
│                     API Gateway (YARP)                          │
│              Autenticação, Rate Limit, Roteamento               │
└─────────────────────────────────────────────────────────────────┘
                              │
        ┌──────────────────┬──┴───────┬────────────────┐
        │                  │          │                │
   ┌────▼────┐      ┌─────▼─────┐  ┌─▼──────┐   ┌────▼─────┐
   │ Catalog │      │  Orders   │  │Payment │   │ Shipping │
   │ Service │      │  Service  │  │Service │   │ Service  │
   └────┬────┘      └─────┬─────┘  └───┬────┘   └────┬─────┘
        │                 │            │             │
        │                 │            │             │
   ┌────▼─────────────────▼────────────▼─────────────▼────┐
   │         RabbitMQ / Azure Service Bus                │
   │    (Events: OrderCreated, PaymentApproved, etc.)   │
   └─────────────────────────────────────────────────────┘

Bancos de Dados:
- Catalog Service: PostgreSQL (dados relacionais)
- Orders Service: SQL Server (transações ACID)
- Payment Service: MongoDB (documentos flexíveis)
- Shipping Service: Redis (cache status rastreamento)

Observabilidade:
- OpenTelemetry: Tracing distribuído
- Prometheus + Grafana: Métricas
- ELK Stack: Logs centralizados

Patterns Implementados:

  • ✅ API Gateway Pattern: YARP para roteamento unificado
  • ✅ Saga Pattern: Orquestração de transações distribuídas
  • ✅ Event Sourcing: Histórico imutável de eventos
  • ✅ CQRS: Separação leitura/escrita por microservice
  • ✅ Circuit Breaker: Polly para resiliência
  • ✅ Outbox Pattern: Garantia entrega de eventos

Tecnologias Recomendadas

Backend

.NET 8, ASP.NET Core, MediatR, FluentValidation, AutoMapper

Persistência

EF Core, Dapper, SQL Server, PostgreSQL, MongoDB, Redis

Mensageria

RabbitMQ, Azure Service Bus, MassTransit

Observabilidade

Serilog, OpenTelemetry, Prometheus, Grafana
