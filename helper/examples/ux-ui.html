Exemplo 1: Dashboard Executivo de Vendas

Contexto:

Dashboard para diretoria acompanhar KPIs de vendas, metas e performance em tempo real.

Personas Identificadas:

  • Diretor Comercial (55 anos): Visão macro, decisões estratégicas, pouco tempo
  • Gerente Regional (38 anos): Acompanhamento equipe, análise tendências
  • Analista BI (28 anos): Relatórios detalhados, exportação dados

Principais Componentes UI:

Layout Responsivo (Desktop First):
┌────────────────────────────────────────────────────────────┐
│  Header: Logo | Período: [▼ Último Mês] | User: [Avatar▼] │
├────────────────────────────────────────────────────────────┤
│  KPI Cards (Principais Métricas)                           │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│  │ Vendas  │ │  Meta   │ │ Ticket  │ │  Conv.  │         │
│  │ R$ 2.8M │ │  85%    │ │ R$ 450  │ │  12.5%  │         │
│  │ ↑ +15%  │ │ 🟡      │ │ ↓ -3%   │ │ ↑ +2%   │         │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘         │
├────────────────────────────────────────────────────────────┤
│  Performance por Região (Gráfico de Barras Interativo)     │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ Sul     ████████████ 120%                           │  │
│  │ Sudeste ██████████ 95%                              │  │
│  │ Nordeste ███████ 78%                                │  │
│  │ Norte   █████ 65%                                   │  │
│  └─────────────────────────────────────────────────────┘  │
├────────────────────────────────────────────────────────────┤
│  Top 10 Vendedores | Produtos Mais Vendidos              │
│  (Tabela Sortável)  | (Gráfico Pizza Interativo)         │
└────────────────────────────────────────────────────────────┘

Interações:
- Hover nos KPIs: Tooltip com detalhamento
- Click gráficos: Drill-down para detalhes
- Filtros: Período, Região, Produto (sidebar colapsável)
- Export: PDF, Excel, CSV (botão flutuante)

Requisitos UX:

  • ✅ Acessibilidade: WCAG 2.1 AA (contraste, keyboard navigation)
  • ✅ Performance: Load < 2s, interações < 100ms
  • ✅ Responsivo: Desktop (1920x1080), Tablet (iPad), Mobile (iPhone)
  • ✅ Cores: Verde (positivo), Vermelho (negativo), Amarelo (atenção)
  • ✅ Tipografia: Roboto (títulos), Open Sans (corpo)

Exemplo 2: App Mobile para Força de Vendas

Contexto:

Aplicativo mobile para vendedores externos registrarem vendas, consultarem catálogo e acompanharem metas.

Jornada do Usuário:

Fluxo Principal (Registrar Venda):
1. Login Biométrico → 2. Home (Metas do dia) → 3. Nova Venda
                              ↓
4. Buscar Cliente → 5. Selecionar Produtos → 6. Aplicar Desconto
                              ↓
7. Resumo Pedido → 8. Confirmar → 9. Assinatura Digital Cliente
                              ↓
10. Sucesso (Comissão Calculada) → Compartilhar PDF

Telas Secundárias:
- Catálogo: Busca por nome, categoria, código
- Metas: Gráfico circular (atingimento), lista produtos pendentes
- Comissões: Histórico mensal, projeção, detalhamento
- Clientes: Busca, histórico compras, localização mapa
- Offline Mode: Sincronização automática quando online

Componentes Mobile Nativos:

  • ✅ Bottom Navigation: Home | Catálogo | Vendas | Metas | Perfil
  • ✅ FAB (Floating Action Button): Nova Venda (ação primária)
  • ✅ Pull-to-Refresh: Atualizar dados em tempo real
  • ✅ Swipe Actions: Editar/Excluir vendas (lista)
  • ✅ Bottom Sheet: Filtros avançados
  • ✅ Snackbar: Feedback de ações (sucesso/erro)

Design System:

  • ✅ Plataforma: Material Design 3 (Android) + Human Interface (iOS)
  • ✅ Cores Primárias: #1976D2 (azul), #4CAF50 (verde sucesso)
  • ✅ Spacing: 4px grid system (8px, 16px, 24px, 32px)
  • ✅ Elevations: Cards (2dp), Modals (8dp), FAB (6dp)
  • ✅ Animações: 300ms ease-in-out (transições padrão)
