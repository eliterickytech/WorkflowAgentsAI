Diagramas do Sistema

📊 Sobre os Diagramas

Esta página contém todos os diagramas de fluxo do ProsoftAgileAgent. Use-os para entender visualmente como o sistema funciona e como os agentes interagem entre si.

Fluxo Manual

Processo manual de execução dos agentes, ideal para começar e entender o sistema. Você executa cada agente individualmente usando os prompts.

flowchart TD A[Start - SPRINT e ACTIVITY] --> B[Criar estrutura com script start manual] B --> C[Insumos em pasta in/sprint/activity/attachments] C --> D[Usar prompts e agentes manuais] D --> E[Gerar arquivos base e pastas features/adrs/diagrams em data/out] E --> F[Revisar artefatos e ajustar] F --> G[Finish] style A fill:#667eea,stroke:#5a67d8,color:#fff style G fill:#48bb78,stroke:#38a169,color:#fff style D fill:#f6ad55,stroke:#ed8936,color:#000

Fluxo Automático (CrewAI)

Execução automatizada usando CrewAI. Os agentes trabalham em sequência automaticamente, com aprovações configuráveis.

flowchart TD A[Start - Configurar Sprint/Activity] --> B[Executar crewai_runner.py] B --> C[CrewAI orquestra agentes] C --> D[Product Owner Agent] D --> E[Requirements Analyst Agent] E --> F[Systems Architect Agent] F --> G[Testing Specialist Agent] G --> H[Expert Developer Agent] H --> I[Testing Validator Agent] I --> J[Product Owner Final Agent] J --> K[Artefatos em data/out] K --> L[Finish] style A fill:#667eea,stroke:#5a67d8,color:#fff style L fill:#48bb78,stroke:#38a169,color:#fff style C fill:#f6ad55,stroke:#ed8936,color:#000
