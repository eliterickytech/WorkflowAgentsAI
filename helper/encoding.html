Padrão de Encoding e Formatação

📋 Padrão Oficial do Projeto

Garantir consistência em todos os arquivos do projeto

Tabela de Encoding Recomendado

Tipo de Arquivo Encoding BOM Line Ending Indent
*.md (Markdown) UTF-8 ❌ Sem BOM CRLF 2 espaços
*.ps1 (PowerShell) UTF-8 ❌ Sem BOM CRLF 4 espaços
*.yaml, *.yml UTF-8 ❌ Sem BOM LF 2 espaços
*.json UTF-8 ❌ Sem BOM LF 2 espaços
*.cs (C#) UTF-8 ✅ Com BOM CRLF 4 espaços
*.ts, *.js UTF-8 ❌ Sem BOM LF 2 espaços

Configuração do VS Code

Arquivo .vscode/settings.json

{
  "files.encoding": "utf8",
  "files.eol": "\n",
  "files.autoGuessEncoding": false,
  "files.insertFinalNewline": true,
  "files.trimTrailingWhitespace": true,

  "[markdown]": {
    "files.encoding": "utf8",
    "files.eol": "\r\n"
  },

  "[powershell]": {
    "files.encoding": "utf8",
    "files.eol": "\r\n"
  },

  "[csharp]": {
    "files.encoding": "utf8bom",
    "files.eol": "\r\n"
  }
}

Arquivo .editorconfig (Raiz do Projeto)

root = true

[*]
charset = utf-8
insert_final_newline = true
trim_trailing_whitespace = true
indent_style = space
indent_size = 2

[*.md]
charset = utf-8
end_of_line = crlf
indent_size = 2

[*.ps1]
charset = utf-8
end_of_line = crlf
indent_size = 4

[*.cs]
charset = utf-8-bom
end_of_line = crlf
indent_size = 4

Validação

Checklist de Validação

  • VS Code mostra UTF-8 (ou UTF-8 with BOM para .cs)
  • Line endings corretos (CRLF vs LF)
  • Usar espaços, nunca tabs
  • Remover trailing whitespace
  • Arquivo termina com newline

🚨 Red Flags

  • Sequências estranhas como A~c ou A~a
  • CRLF e LF misturados no mesmo arquivo
  • Markdown salvo com BOM
  • C# sem BOM
  • Tabs misturados com espaços
