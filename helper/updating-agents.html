Atualizando Agentes

🔄 Mantenha os Agentes Atualizados

Guia para atualizar, personalizar e manter os agentes especializados do WorkflowAgentDev.

Processo de Atualização

1

Backup

Sempre faça backup da pasta agents/ antes de atualizar

2

Pull Latest

Obter última versão do repositório oficial

3

Mesclar Customizações

Reintegrar suas personalizações específicas

4

Testar

Validar que agentes funcionam conforme esperado

Comandos Git

# Backup manual
cp -r agents agents_backup

# Atualizar do repositório oficial
git pull origin main

# Ver diferenças
git diff HEAD~1 agents/

# Reverter se necessário
git checkout HEAD~1 -- agents/

Boas Práticas

Versionamento

Manter agentes customizados em branch separada

Documentação

Documentar todas as customizações feitas

Testes

Testar após cada atualização em ambiente não-produção

Changelog

Manter registro de mudanças e motivos

Estrutura de Customização Recomendada

agents/
├── manual/                    ← Agentes oficiais
│   └── *.agent.md
└── custom/                    ← Suas customizações
    ├── company-specific.instructions.md
    └── domain-specific.instructions.md

Enriquecimento de Agentes

Durante a instalação, você pode enriquecer automaticamente os agentes com instruções personalizadas:

.\Install\setup-workflow.ps1

Deseja enriquecer os agentes? (s/n): s
Pasta com arquivos .instructions.md: C:\MinhasInstrucoes

[INFO] Enriquecendo 11 agentes...
[INFO] product-owner.agent.md enriquecido
[INFO] systems-architect.agent.md enriquecido
...

Avisos Importantes

  • ⚠️ Nunca edite agentes diretamente sem backup
  • ⚠️ Teste sempre em ambiente de desenvolvimento primeiro
  • ⚠️ Documente todas as mudanças para referência futura
  • ⚠️ Mantenha consistência entre todos os 11 agentes
  • ⚠️ Verifique compatibilidade ao atualizar versões
