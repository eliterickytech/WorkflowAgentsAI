🏗️ Arquitetura

  • Clean Architecture: Domain, Application, Infrastructure, Presentation
  • DDD Patterns: Entities, Value Objects, Aggregates, Domain Services
  • CQRS: Commands e Queries separados com MediatR
  • Result Pattern: Retorno tipado com sucesso/erro

✅ Validação

  • FluentValidation: Para validação de inputs
  • Custom Error Codes: Códigos de erro específicos
  • Domain Validation: Validação no domínio

📊 Logging

  • Serilog: Structured logging obrigatório
  • Context Enrichment: Adicionar contexto às logs
  • Sem Console.WriteLine: Usar logger estruturado

⚙️ Configuração

  • Strongly Typed Options: IOptions<T>
  • Validation on Startup: Validar configurações
  • Environment-Specific: appsettings por ambiente

🗄️ Data Access

  • Repository Pattern: Abstrair persistência
  • Entity Framework Core: ORM recomendado
  • Migrations: Para mudanças de schema
  • Unit of Work: Para transações

🧪 Testing

  • Cobertura: >= 90% em módulos críticos
  • Testes Determinísticos: Sem aleatoriedade
  • Arrange-Act-Assert: Padrão AAA
  • xUnit: Framework recomendado
