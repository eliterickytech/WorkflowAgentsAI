Setup de Novo Projeto .NET

🚀 Do Zero ao Workflow Completo

Guia para adotar o workflow em um projeto .NET novo. Ideal para quem tem apenas especificação e quer produzir artefatos de engenharia completos.

Instalação Automática

Caminho Automático (Recomendado)

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install\setup-workflow.ps1

O instalador faz tudo sozinho:

  • ✅ Checa/instala pré-requisitos
  • ✅ Copia pastas necessárias
  • ✅ Cria ambiente virtual Python (`.venv-1`)
  • ✅ Instala dependências do `requirements.txt`
  • ✅ Pode enriquecer agentes automaticamente

Pré-requisitos (Windows + VS Code)

VS Code

Extensões: Python, Pylance, PowerShell

.NET SDK

Recomendado .NET 8

Python

3.10 ou superior

Node.js

LTS (para renderizar diagramas)

Instalação rápida com winget

# Instalar pré-requisitos
winget install Microsoft.VisualStudioCode
winget install Microsoft.DotNet.SDK.8
winget install Python.Python.3.12
winget install OpenJS.NodeJS.LTS

O que será copiado

SeuNovoProjetoNET/
├── agents/                  ← Agentes especializados
├── orchestrators/           ← Scripts Python (CrewAI/AutoGen)
├── scripts/powershell/      ← Scripts úteis
├── src/workflow_agents/     ← Assets e prompts
├── docs/                    ← Guias e exemplos
├── requirements.txt         ← Dependências Python
└── .env.example             ← Modelo de variáveis

⚠️ Importante

NÃO copie a pasta `.venv-1` (ambiente virtual Python). Será criada automaticamente no seu projeto.
