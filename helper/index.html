WorkflowAgentDev - Sistema de Agentes Inteligentes

🎯 O que é?

O WorkflowAgentDev é um sistema de agentes inteligentes que automatiza o processo completo de desenvolvimento de software seguindo metodologias ágeis.

Transformamos uma simples solicitação de negócio em documentação completa, código implementado e planos de teste.

11 Agentes Especializados

Product Owner, Arquiteto, Developer, QA e mais

Execução TDD

Testing Specialist cria plano ANTES do código

Execução Paralela

Múltiplas atividades simultaneamente

GitHub Copilot

Integração automática com IA

💡 Importante

Cada agente pede sua aprovação antes de continuar para o próximo!

Você tem controle total sobre o processo e pode revisar/ajustar cada etapa.

Quick Start

1️⃣ Instalação

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install\setup-workflow.ps1

Execute o instalador e siga as instruções

2️⃣ Adicionar Documentos

Coloque seus documentos em:

data/in/sprint01/activity01/
├── business_request/
└── attachments/

3️⃣ Executar Product Owner

Use o prompt do agente:

agents/manual/product-owner.agent.md

No ChatGPT ou Claude

4️⃣ Seguir o Fluxo

Continue com os próximos agentes em sequência
